# 01 · MVP 范围

> ⚠️ 2026-06-02 重大变更：从"通用文生图 MVP"改为"**爆款一键复刻 MVP**"。详见 [CHANGELOG.md](./CHANGELOG.md)。
> 本文档与 [.claude/prds/vaneai.prd.md](../.claude/prds/vaneai.prd.md) 保持一致。

## 范围（IN）

### 用户系统
- [ ] 邮箱 + Magic Link 登录（Supabase Auth）
- [ ] OAuth：Google 一键登录
- [ ] 用户 profile（display_name、avatar）
- [ ] 登出

### 核心：模板库 + 一键复刻
- [ ] **爆款模板库** — 编辑精选，首批 30–50 条
  - [ ] 列表页：缩略图 + 标题 + 主题标签
  - [ ] 详情页：参考图 + 1–2 张示范产出 + 推荐尺寸 + 「一键复刻」按钮
  - [ ] 主题筛选（游戏角色概念 / 盲盒手办风）
- [ ] **一键复刻** — 选模板 → 输入主体关键词 → 生成
  - [ ] 主体关键词输入框（中英文，单行，≤ 60 字）
  - [ ] 推荐尺寸已由模板预设（用户不需选）
  - [ ] **不暴露任何 prompt 编辑面板**
  - [ ] 生成中状态 + 取消按钮
- [ ] **结果展示**
  - [ ] 大图预览
  - [ ] 「再次复刻」（同模板换关键词）
  - [ ] 「换个模板」入口
  - [ ] 下载图片
  - [ ] 60 秒倒计时埋点（用于"成功复刻"度量）
- [ ] **个人作品库**
  - [ ] 时间倒序列表 + 游标分页
  - [ ] 详情：复刻使用的模板、关键词、生成时间
  - [ ] 「再次复刻」入口（复用上次关键词）
  - [ ] 删除（软删，定时清理 storage）

### 任务管理
- [ ] 任务状态机：`pending → running → succeeded | failed | canceled`
- [ ] 前端轮询（或订阅 Supabase realtime）
- [ ] 取消任务（已扣积分不自动回补）
- [ ] 失败重试（用同模板 + 同关键词重跑）

### 配额与积分（轻量版）
- [ ] 注册赠送 100 积分
- [ ] 单次复刻消耗积分（按模板配置）
- [ ] 每用户每天 N 次免费配额（默认 10 次）
- [ ] 余额不足明确提示（不接支付）
- [ ] 失败任务自动回补积分（积分流水可查）

### 编辑后台（仅 admin 白名单）
- [ ] **模板管理**（CRUD）
  - [ ] 上传参考图
  - [ ] 输入 base prompt（用户不可见）
  - [ ] 设定推荐尺寸 + 单次消耗积分
  - [ ] 上传 1–2 张示范产出
  - [ ] 上下架（is_active 切换）
  - [ ] 主题分类管理
- [ ] 任务列表（按用户、状态筛选）
- [ ] 失败原因查看
- [ ] 用户列表 + 手动加积分

### 基础合规
- [ ] 服务条款 / 隐私政策（落地页静态页）
- [ ] 关键词黑名单（涉黄涉政基本拦截）
- [ ] NSFW 内容过滤（依赖 fal.ai 默认能力）

## 不在范围（OUT）

详见 [08-non-goals.md](./08-non-goals.md) 与 PRD 的 Out of scope 章节。重点：

| 不做 | 为什么 |
|---|---|
| ❌ **自由 prompt 输入** | 与产品定位冲突；要 prompt 自由请用 MJ/Liblib |
| ❌ **上传参考图复刻** | V2 再做 |
| ❌ 任何视频功能 | V2/V3 才启动 |
| ❌ UGC 模板上传 | 冷启动期没用户也就没内容 |
| ❌ 支付 / 订阅 | 先验证留存数据 |
| ❌ 社区、广场、点赞、评论 | 不是 MVP 护城河 |
| ❌ ControlNet / LoRA / Inpainting / 训练 | 与"一键复刻"承诺冲突 |
| ❌ 多语言 i18n、移动 App | 中文 web 响应式起步 |
| ❌ 模板自动从外网抓取 | 版权 + 反爬风险 |
| ❌ Prompt 优化器 | 用户不写 prompt |

## 验收标准（Done = ?）

MVP 视为完成需满足全部：

1. 真实用户从 0 起步，3 分钟内完成首次成功复刻
2. 文生图 P50 ≤ 15 秒，P95 ≤ 60 秒
3. 任务失败率 ≤ 5%（不含用户主动取消）
4. 单用户单日 10 次配额生效
5. 失败任务自动回补积分（积分流水可查）
6. RLS 启用，跨用户访问 0 命中（手动 + 自动测试）
7. Sentry 接入，关键错误有告警
8. Vercel + Supabase 生产环境跑通，域名配置完成
9. **首批 30–50 条模板已上线，覆盖游戏角色概念 + 盲盒手办风两个主题**
10. 后台埋点收齐：注册、首次复刻、N 次复刻、模板点击、关键词输入、失败、取消、删除、60s 内重试

## 关键风险与对策

| 风险 | 对策 |
|------|------|
| **模板内容版权** | 仅使用编辑团队自行生成的参考图，或购买授权图库 |
| **复刻精度不达预期** | W2 单次闭环时实测；不达标先调 fal.ai 模型/参数 |
| **运营节奏跟不上** | W1 试运营 1 周确认产出节奏；标准化模板录入流程 |
| Provider 抖动 | Provider 抽象层留备选位，必要时切 Replicate |
| 用户滥用免费额度 | 同 IP 限速 + 邀请码（如需） |
| 涉黄涉政内容 | 关键词黑名单 + fal.ai 默认安全过滤 + 用户协议 |
| Vercel function 超时 | 异步任务全走 Inngest，不放 Vercel function |
| Supabase 免费额度耗尽 | 监控 Storage/DB 用量；定时清理软删资产 |
| **用户不愿填关键词，要"完全免输入"** | 关键词输入框可预填模板默认词；W5 内测验证 |
| **自由 prompt 用户因受限流失** | 接受这个权衡；MVP 严格不开口子 |
