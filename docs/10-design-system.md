# 10 · VaneAI 设计系统 v3 ——「头条日报 / The Front Page」

> 2026-06-11 v3，取代同日 v2「暗厅画廊」（git 历史可查）。v3 = v2 的明暗极性翻转：
> 壳层（导航/模板库/作品库/营销页）回到**暖纸光面刊物**，暗厅暖碳只保留给**生成工作台**（按面经 `.dark` 开启）。
> 定位：**视觉优先的 Editorial Gallery（光面）+ 克制的深色生成工作台（暗面）**。
> 原则：图片占据视觉主导；界面退后衬托作品；信息默认弱化、悬停浮现；
> 品牌色（朱红）只用于「生成动作」与「状态反馈」；导航是创作工具的案头，不是后台系统。

技术基座：Tailwind v4 + shadcn base-nova / Base UI（只取其**无障碍行为**：菜单、对话框、焦点管理）。
**禁止**：照搬 shadcn 默认主题色、默认 Card 结构、默认 Dashboard 布局（sidebar + 统计卡）。
Token 唯一来源 `app/globals.css`；业务代码禁用原始色板类。

## 1. 品牌色与语义色 Token

**浅色（暖纸刊物面）为默认主题**（`:root` 即浅色）；深色暖碳工作台收在 `.dark` 类下，**按面（per-surface）开启**。

### 浅色（默认 · 头条日报纸面）

| Token | 值 | 用途 |
|---|---|---|
| `background` | `#FAF7F2` 暖白纸面 | 壳层底色（非纯白，衬托作品） |
| `card` | `#FFFFFF` 照片纸 | 卡片、浮起面 |
| `secondary` / `muted` / `accent` | `#F0EBE3` | 次级面、hover 面 |
| `foreground` | `#1C1917` 墨黑 | 标题/正文 |
| `muted-foreground` | `#6E675F`（暖白上 ≥4.5:1） | 辅助文字下限，不得更浅 |
| `border` | `#1C1917 / 12%` 墨色发丝线 | 分隔、卡片描边 |
| `input` | `#1C1917 / 22%` | 表单描边 |
| `primary` | `#1C1917`（墨） | 常规主操作（非生成类按钮） |
| `ring` | `#8A847A` | 焦点环 |
| **`brand`** | **`#BE3009` 朱红（深）** | **仅限：生成 CTA、报头线、生成中状态、热度印章** |
| `brand-foreground` | `#FFFFFF` | 朱红底上的白字（≥4.8:1） |
| `success` | `#15803D` | 生成完成 |
| `destructive` | `#BE123C` 玫红 | 失败/删除——**刻意偏玫调，与朱红拉开**，避免语义混淆 |

### 深色（`.dark` · 暖碳生成工作台，按面开启）

| Token | 值 |
|---|---|
| `background` | `#141110` 暖碳（禁纯黑，保留暖度） |
| `card` | `#1D1916`；`popover` `#262019`（暗面靠明度分层，不靠阴影） |
| `foreground` | `#F4F0E8` 暖纸白 |
| `muted-foreground` | `#A6A099`（暗底 ≥4.6:1，不得更暗） |
| `border` | `#F4F0E8 / 10%`；`input` `#F4F0E8 / 16%` |
| `primary` | `#F4F0E8`（墨白反转） |
| `brand` | `#FF4118` 朱红（亮），`brand-foreground` `#1A0D08`（对比 >7:1） |
| `success` | `#4ADE80`；`destructive` `#FB7185` |

**明暗过渡规则**：壳层（顶栏、模板库、作品库、营销页、admin）一律光面；生成类工作台页（如 `/create`）整页容器加 `.dark` 进入暖碳层，顶栏壳层保持光面——明暗交界即「进入创作」的空间暗示。禁止在同一面内混用两套极性。

**朱红使用纪律（全站红线）**：允许出现的位置只有——①「开始创作」/「一键复刻」类生成入口；②生成中进度与呼吸灯；③报头装饰线；④成功/热度类状态印记（如"爆"章）。导航活动态、筛选选中态、链接、悬停一律不得使用朱红。

## 2. 字体

```
display（刊头/标题）: "Noto Serif SC" 700/900 → Georgia, serif
body（正文/界面）  : Geist → "Noto Sans SC" → PingFang SC → 雅黑
data（数字/编号）  : Geist Mono + font-variant-numeric: tabular-nums
```

- 衬线只用于**页面标题、模板名、空状态标语**——刊物感的来源；按钮、表单、导航一律无衬线。
- 所有积分、计数、尺寸、编号（`NO.012`、`1024×1024`、`CR 100`）用等宽 + tabular-nums，数字变化不跳版。
- 中文标题禁 `tracking-tight`；等宽 Latin 标签可 `tracking-wider` + 大写。

## 3. 字号 / 间距 / 圆角 / 边框 / 阴影

**字号**（serif=衬线，mono=等宽）：

| 用途 | 规格 |
|---|---|
| 刊头/营销 display | serif 900，`clamp(2.5rem, 6vw, 4rem)`，行高 1.1 |
| 页面 H1 | serif 700 / 30px |
| 区块 H2 / 卡片悬停标题 | serif 700 / 20px |
| 正文 | sans 16 / 行高 1.7 |
| 次要 | sans 14 |
| 元数据/编号 | mono 12，大写 Latin |

**间距**：4px 基准。组件内 8–12；卡片网格 gutter **16**（画廊密排）；区块间 **64**；页面纵向 `py-12 sm:py-20`（编辑式大留白）。

**圆角**：`--radius: 4px` 上限——硬边是编辑风格的一部分。控件 4px；**图片与卡片 2px**；禁胶囊、禁大圆角；全圆仅限状态点。

**边框**：发丝线（1px 低透明度）是主要分层手段；装饰性"四角刻线/对位十字"不承载信息。

**阴影**：深色模式**不用投影**，层级靠 surface 明度阶梯；浅色模式仅 Dialog 允许一档 `0 16px 40px -12px rgb(28 25 23 / 0.25)`。

## 4. 图片比例与裁切规则

- 模板图入库归入**三个比例桶**：`3:4`（竖，默认）、`1:1`（方）、`4:5`；列表一律 `object-cover`，焦点 `center 25%`（人物头部安全区）。
- 列表网格：**非等高编辑网格**——4 列 grid，行高 8px 基准，卡片按比例桶预排 row-span；**头版位**（sort_order 第一）跨 2 列。秩序感优先于 Pinterest 式乱流。
- 详情页：原始比例完整展示（contain），衬 `surface` 底，禁拉伸、禁列表内上下留黑边。
- 所有图片声明尺寸或 aspect-ratio（防 CLS），首屏外 `loading="lazy"`，占位为 `surface` 色块。

## 5. 模板卡片——全部交互状态

卡片 = 暗厅里的一幅作品：**默认只有图**，信息层悬停浮现。

| 状态 | 表现 |
|---|---|
| default | 图片 + 2px 圆角 + 发丝线描边；左上角 mono 编号 `NO.001`（40% 透明度）；无标题无标签 |
| hover | 底部 40% 升起暗部渐变纱（`#141110/0 → /85`）；浮现：serif 模板名 + mono 主题标签 + 「复刻 →」提示；图片亮度 105%、scale 1.02（320ms ease-out）；编号变实 |
| focus-visible | 2px `ring` 外描边 + 2px offset，信息层同 hover 浮现（键盘可达同等信息） |
| active/按压 | scale 0.985，100ms |
| **触屏（`hover:none`）** | 信息层不可依赖悬停——常驻一行紧凑字幕（模板名 + 编号），渐变纱常显 30% |
| loading | `surface` 色块 + 微 shimmer（reduced-motion 时静止） |
| 热门 | 右上角朱砂「爆」印章（旋转 -2°，serif），这是卡片上唯一允许的品牌色 |

## 6. 导航与筛选器规范

**顶栏 = 创作台案头**，不是 admin bar：

- 左：**衬线刊头词标 `VaneAI`**（去图形 logo 方点，刊头即标志）
- 中：`模板库 / 我的作品` 文字导航——活动态为 **2px 前景色下划线**（不用朱砂），56px 满高点击区
- 右：积分读数 `CR 100 · 今日 0/10`（mono，点击展开明细）+ **「开始创作」朱砂实底按钮——全站唯一的常驻品牌色元素、唯一主入口**（高 40/44px，硬边 4px）
- 移动端：顶栏保留词标 + 「开始创作」（缩为短词），导航文字项保持单行；不引入汉堡菜单
- 账户入口收进词标右侧或积分读数的下拉（Base UI Menu，保无障碍）

**筛选器 = 刊物版块目录**，不是胶囊 pill：

- 文字 tab + 计数：`全部 32 / 游戏角色 16 / 盲盒手办 16`（计数 mono）
- 选中态：前景色 2px 下划线 + 文字全亮；未选中 `muted-foreground`，hover 半亮
- 高度 ≥44px 触控；`aria-current="page"`；横向可滚动不换行（窄屏）

## 7. 动效时长与 easing

| Token | 值 | 用途 |
|---|---|---|
| `fast` | 120ms | 文字/透明度微变 |
| `base` | 200ms | 控件状态、盖章式进场（scale 1.04→1，**无弹簧**） |
| `reveal` | 320ms | 图片显影（opacity 0→1 + brightness 0.8→1） |
| stagger | 30ms/张，总长 ≤500ms | 网格进场 |
| easing | 进 `cubic-bezier(0.2, 0, 0, 1)`；出 ease-in，时长 ×0.7 | 全局统一 |

- 生成中：朱砂呼吸灯点（1.6s 循环）+ 进度条，是动效优先级最高的场景
- hover 位移仅卡片 scale 与渐变纱；导航/按钮 hover 只变色不位移
- `prefers-reduced-motion`：全部归零（已有全局兜底），shimmer/呼吸灯改静态

## 8. 五态规范（loading / empty / error / success / 生成中）

| 状态 | 规范 |
|---|---|
| **loading** | 路由级骨架与实页同构；色块 `surface`→`surface-raised` shimmer；超 1s 的操作必须有骨架或进度，禁纯 spinner 满屏 |
| **empty** | 编辑式排版：serif 大标语（如"这一期还没有作品"）+ 一句说明 + 「开始创作」入口；装饰用对位十字/刻线，**不用** shadcn Empty 默认图标盒 |
| **error** | 玫红发丝框面板：serif 短标题 + 人话原因 + mono 错误码（小字）+ 重试按钮；表单错误贴字段下方，玫红 + `aria-live="polite"`；超时必须给出路（如"去作品库查看"带链接） |
| **success** | 生成完成：结果图显影动效 + 朱砂→前景色的一次性闪光勾 + toast（3.5s 自动消失，不抢焦点）；下载/再次复刻按钮同帧出现 |
| **生成中** | 朱砂呼吸灯 + 阶段文案（排队中→生成中）+ 进度条 + 已耗时（mono）；可取消；结果区预留版面防跳动 |

## 9. shadcn / Base UI 使用边界

| 用 | 不用 |
|---|---|
| Menu/Dialog/AlertDialog/Tabs/Toast 的**行为与无障碍**（焦点圈定、Esc、aria） | 默认主题 token（全部换本规范） |
| Button/Input 的结构与表单语义 | 默认 Card —— 模板卡、信息面板全部自定义 |
| Skeleton/Progress 原语 | Dashboard 布局范式（sidebar、统计卡阵列） |

定制层落位：`components/ui/`（改 token 后的原语）+ `components/studio/`（新建：模板卡、编辑网格、生成进度、状态面板等品牌组件）。

## 10. 与 v1 / v2 的差异摘要

**对 v1**：品牌色由陶土橙 `#C2410C` 改为朱红双值 `#BE3009 / #FF4118` 且用途收窄到生成与状态；新增 Noto Serif SC 衬线标题层；圆角 8px→4px 上限；卡片从"白卡+常显信息"改为"作品优先+悬停浮现"；网格从等高 2/3/4 列改为比例桶编辑网格 + 头版位；新增「开始创作」常驻主入口；筛选从胶囊改为版块目录。

**对 v2**：明暗极性翻转——壳层从暗厅回到暖纸光面（`:root` 即浅色），暗厅暖碳收窄为生成工作台专用（`.dark` 按面开启，见 §1 明暗过渡规则）；其余规范（字体、网格、卡片交互、动效、五态）沿用 v2。

## 11. 迁移顺序（待批准后执行）

① token + 字体 + 基础组件重调 → ② 壳层导航（含开始创作）→ ③ 模板库编辑网格 + 新卡片 → ④ 模板详情/生成反馈 → ⑤ 作品库 → ⑥ 落地页/登录页。
